# Material Museum



1) Which material looked the most realistic?
    - The metal material created with the MeshStandard; it's pretty hard to mess up a metallic object
2) Which material looked the most cartoon-like?
    - the toon Material
3) Which material would you use for a metal robot?
    - MeshStandard or MeshNormal with a metalic and shininess param
4) How did adding the spotlight affect the scene?
    - Adding a spotlight changed how some of the objects looked under more lighting that was also a different color. My favorite effect was the light on the mystery object creating cool prism effects
